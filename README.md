# Beads Task vs Schizotypy Analysis Dashboard

This repository contains an interactive Streamlit dashboard for analyzing the relationship between performance on the beads drawing task and schizotypy scores.

## Files

- `dashboard.py`: Main Streamlit dashboard application for data visualization and analysis
- `participant_avg_dtd.csv`: Participant average draws-to-decision data
- `schizotypy.csv`: Participant schizotypy scores based on the O-LIFE questionnaire
- `trial_wise_data_2.csv`: Detailed trial-level data from the beads task experiment

## Features

- Comprehensive correlation analysis between beads task metrics and schizotypy dimensions
- K-means clustering with elbow chart for optimal cluster determination
- Detailed participant-level analysis with pattern matching
- Interactive visualizations of evidence gathering behavior across different jar ratios (15/85 and 60/40)

## Schizotypy Subscales

The dashboard analyzes the Oxford-Liverpool Inventory of Feelings and Experiences (O-LIFE) questionnaire with four subscales:
- SS1: Unusual Experiences
- SS2: Cognitive Disorganisation
- SS3: Introvertive Anhedonia
- SS4: Impulsive Nonconformity
